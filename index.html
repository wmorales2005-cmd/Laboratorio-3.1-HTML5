Introducción

Esta página fue desarrollada como parte del Laboratorio 3.1. El propósito es demostrar el uso de las principales etiquetas de HTML5 y aplicar una estructura semántica correcta.

HTML permite crear la estructura de una página web, mientras que CSS permite modificar su presentación y diseño.

Características de HTML5

¿Qué es HTML5?

HTML5 es la versión moderna del lenguaje utilizado para estructurar contenido en páginas web.

Algunas características importantes

  • Uso de etiquetas semánticas.
  • Compatibilidad con audio y video.
  • Uso del elemento canvas.
  • Mejor organización del contenido.
  • Compatibilidad con diferentes dispositivos.
