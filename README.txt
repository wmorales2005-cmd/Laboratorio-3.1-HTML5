Descripción:

Este proyecto fue desarrollado para demostrar los conceptos básicos
de HTML y HTML5.

La página incluye:

- Encabezados.
- Párrafos.
- Listas.
- Enlaces.
- Imágenes.
- Etiquetas semánticas de HTML5.
- Header.
- Nav.
- Main.
- Section.
- Article.
- Footer.
- Figure.
- Figcaption.
- Audio.
- Video.
- Canvas.
- CSS para modificar la apariencia de la página.

El proyecto fue creado utilizando Visual Studio Code y posteriormente
publicado en GitHub.
